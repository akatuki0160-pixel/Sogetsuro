# SOGETSURO 古民家ポータルサイト テンプレート

古民家の宿サイトでよく使われる構成（全画面スライドショー、縦書きのコピー、客室紹介、予約導線など）を、HTML / CSS / JavaScript で一から制作したオリジナルのテンプレートです。

- 文章・写真はすべてダミーです。写真は「同じファイル名で上書き」するだけで差し替えられます。
- 参考サイトの文章・写真・ソースコードは含んでいません（著作権保護のため）。レイアウトの考え方だけを参考に、独自に制作しています。
- ライブラリは不要です（jQuery やスライダーのプラグインも使っていません）。

---

## フォルダ構成

```
static/                    … サーバーにそのままアップロードする版（静的サイト）
├─ index.html
└─ assets/
   ├─ css/style.css
   ├─ js/main.js
   └─ img/                 … ダミー画像（26枚）+ favicon.svg

wordpress/                 … WordPress に貼り付ける版
├─ 01-html-block.html      → 固定ページの「カスタムHTML」ブロックへ
├─ 02-custom.css           → 追加CSS（CSS入力欄）へ
├─ 03-custom.js            → カスタムJS（フッター）へ
└─ template-sogetsuro.php  → ヘッダー・フッターなしのページテンプレート（推奨）
```

`wordpress/` の CSS・JS は `static/assets/` と同じ内容です。HTML の違いは画像のパスと、`<main>` を `<div>` にしている点だけです。

---

## A. サーバーにアップロードして表示する（静的サイト）

1. `static` フォルダの中身をそのままサーバーへアップロードします（例：`public_html/`）。
2. ブラウザで `index.html` のURLを開くと、そのまま表示されます。
3. 公開前に、`index.html` の `og:url` と `og:image` を本番のURLに書き換えてください。

---

## B. WordPress で表示する

### 1. 画像をアップロード
`static/assets/img/` の画像を、FTP またはサーバーのファイルマネージャーで次の場所にアップロードします。

```
/wp-content/uploads/sogetsuro/
```

- メディアライブラリにアップロードする場合は、HTML の `/wp-content/uploads/sogetsuro/` を各画像のURLに置き換えてください。
- WordPress をサブディレクトリに設置している場合は、パスの先頭にそのディレクトリ名を付けてください（例：`/wp/wp-content/uploads/sogetsuro/`）。

### 2. ページテンプレートを入れる（推奨）
`wordpress/template-sogetsuro.php` を、使用中のテーマ（できれば子テーマ）のフォルダ直下にアップロードします。
固定ページの編集画面で、右側の「テンプレート」から **「SOGETSURO（ヘッダー・フッターなし）」** を選んでください。

- テーマのヘッダー・フッター・ページタイトル・サイドバーが消え、画面いっぱいに表示されます。
- テンプレートを使わない場合は、テーマの本文幅の中に小さく表示され、ヘッダーも二重になります。
- ブロックテーマ（Twenty Twenty-Five など）の場合は、「外観 → エディター → テンプレート」で「投稿コンテンツ」ブロックだけの空のテンプレートを作り、ページに割り当ててください。

### 3. HTML を貼り付ける
固定ページに **「カスタムHTML」ブロック** を追加し、`01-html-block.html` の中身をすべて貼り付けます。

- **管理者アカウント**で貼り付けてください。管理者以外の権限では、`<script>` `<style>` `<svg>` が自動で削除されることがあります（マルチサイトではネットワーク管理者のみ貼り付けられます）。
- クラシックエディターは自動整形でレイアウトが崩れるため、ブロックエディターのカスタムHTMLブロックを使ってください。

### 4. CSS を貼り付ける
`02-custom.css` をすべてコピーし、次のいずれかに貼り付けます。

- 外観 → カスタマイズ → 追加CSS（クラシックテーマ）
- 外観 → エディター → スタイル → 追加CSS（ブロックテーマ）
- テーマやプラグインの「カスタムCSS」入力欄

CSS はすべて `.sg-site` の内側だけに効くように書いているため、サイト全体に読み込んでも他のページには影響しません。

### 5. JavaScript を入れる
`03-custom.js` を、次のどちらかの方法で読み込みます。

- テーマやプラグインの「カスタムJS」機能で、**フッター**に出力する
- 「カスタムHTML」ブロックの一番最後に、`<script>` と `</script>` で囲んで貼り付ける

JS は、本文に直接貼っても WordPress の自動変換で壊れないように書いています（`&` 記号を使っていません）。

### 6. 公開して確認
- キャッシュ系のプラグインを使っている場合は、キャッシュを削除してから確認してください。
- 画像の遅延読み込みや、CSS・JS の結合を行うプラグインで表示がおかしくなる場合は、このページを対象外にしてください。

## 編集ガイド

### 色・フォント・余白を変える
HTML の `<style id="sogetsuro-settings">` の値を書き換えると、サイト全体に反映されます。

- 静的版：`static/index.html` の `<head>` 内
- WordPress版：`01-html-block.html` の先頭（貼り付けたカスタムHTMLブロックの先頭）

| 変数 | 用途 | 初期値 |
| --- | --- | --- |
| `--sg-c-bg` | 背景 | `#f4f1ea`（生成り） |
| `--sg-c-bg-sub` | 背景・サブ（お知らせ・町を歩く） | `#ebe5da` |
| `--sg-c-text` | 文字 | `#2b2724`（墨） |
| `--sg-c-text-sub` | 補足の文字 | `#6f675d` |
| `--sg-c-accent` | アクセント（番号・予約ボタン） | `#8b3d2c`（弁柄） |
| `--sg-c-dark` | 暗い背景（食べる・メニュー・フッター） | `#211e1b` |
| `--sg-c-dark-text` | 暗い背景の上の文字 | `#ece6da` |
| `--sg-c-dark-accent` | 暗い背景の上のアクセント | `#c49a6c`（金茶） |
| `--sg-f-ja` / `--sg-f-en` | 和文 / 欧文フォント | Shippori Mincho / Cormorant Garamond |
| `--sg-w-inner` | コンテンツの最大幅 | `1200px` |

コメントに配色サンプル（藍・松葉・墨）も入れてあります。

> 設定を CSS ファイルではなく HTML に置いているのは、古い WordPress の追加CSS や構文チェック付きのプラグインでは、CSS変数の定義（`--xxx: ...`）がエラー扱いになり保存できないことがあるためです。`02-custom.css` は WordPress 同梱の CSSLint（v1.0.4）でエラーが出ないことを確認しています。

### 写真を差し替える
同じファイル名・なるべく同じ縦横比の写真で上書きすれば完了です。ダミー画像の中央に、ファイル名・サイズ・用途が書いてあります。

| ファイル名 | 使う場所 | 推奨サイズ（px） |
| --- | --- | --- |
| `hero-01.jpg` 〜 `hero-03.jpg` | メインビジュアル（スライドショー） | 2400 × 1500 |
| `concept-01.jpg` | はじめに（縦長） | 1200 × 1600 |
| `concept-02.jpg` | はじめに（横長） | 1200 × 800 |
| `stay-01.jpg` 〜 `stay-03.jpg` | 泊まる（客室1〜3） | 1800 × 1200 |
| `dining-01.jpg` | 食べる（大） | 1800 × 1200 |
| `dining-02.jpg` | 食べる（小・縦長） | 900 × 1200 |
| `exp-01.jpg` 〜 `exp-04.jpg` | 体験カード | 1000 × 1250 |
| `town-01.jpg` | 町を歩く（横長パノラマ） | 2400 × 1200 |
| `gallery-01.jpg` 〜 `gallery-08.jpg` | 流れるギャラリー（奇数：縦長、偶数：横長） | 900 × 1200 / 1200 × 800 |
| `reserve.jpg` | ご予約の背景 | 2400 × 1400 |
| `menu.jpg` | メニューを開いたときの左側（PC） | 1200 × 1600 |
| `ogp.jpg` | SNSでシェアされたときの画像 | 1200 × 630 |

写真は JPEG で 1 枚 300KB 前後を目安に圧縮すると、表示が速くなります。縦横比を変える場合は、HTML の `width` / `height` の数値も合わせて変えてください。

### 文章・リンクを差し替える
| 内容 | 探すキーワード |
| --- | --- |
| 住所 | `〇〇` |
| 電話番号 | 表示の `0000-00-0000`（4か所）と、リンクの `tel:0000000000`（5か所） |
| リンク先が未設定のボタン（予約・詳しく見る・SNS など） | `href="#"` |
| お知らせ | `sg-news__item`（1件ずつ `<li>` を増減） |
| Googleマップ | `sg-access__map-dummy` の `<div>` を、Googleマップの「共有 → 地図を埋め込む」でコピーした `<iframe>` に置き換え |

### スライドショー
- 切り替えの間隔：`data-interval="6000"`（ミリ秒）
- 枚数：`<figure class="sg-hero__slide">` を増減してください（最初の1枚だけ `is-active` を付けます）。

### アニメーション
| 指定 | 動き |
| --- | --- |
| `class="sg-reveal"` | スクロールで下からふわっと表示 |
| `class="sg-reveal sg-reveal--mask"` | 写真が幕のように上から開く |
| `class="sg-reveal sg-reveal--v"` | 縦書きの文字が上からふわっと表示 |
| `style="--d:.2s"` | 表示を 0.2 秒遅らせる |
| `data-sg-parallax="0.15"` | 写真のパララックス（数値が大きいほど強く動く） |

ローディング画面は最初の1回だけ表示され、同じタブで再読み込みしたときは省略されます。

### ロゴ
- 円窓のマーク：HTML の `<symbol id="sg-emblem">` の中の SVG を差し替えると、ヘッダー・フッター・ローディングすべてに反映されます。
- 文字のロゴ：`SOGETSURO` / `古民家の宿` を検索して書き換えてください。

## 動作環境・確認済みのこと
- 最新の Chrome / Edge / Safari / Firefox、iOS Safari、Android Chrome を対象としています。
- JavaScript が無効でも内容はすべて表示されます（アニメーションなし）。JS の読み込みに失敗したときも、4秒後に自動で表示されます。
- OS の「視差効果を減らす」「動きを減らす」設定がオンの場合は、動きを止めて表示します。
- PC（1440px）とスマホ（390px）で表示を確認し、エラーや横スクロールが出ないことを確認しました。
- WordPress（Twenty Twenty-One）で、カスタムHTMLブロックに貼り付けた HTML・JS が変換されずにそのまま出力されること、追加CSSで保存できること、同梱テンプレートで静的版と同じ表示になることを確認しました。
