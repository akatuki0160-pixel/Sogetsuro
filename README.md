# SOGETSURO 古民家ポータルサイト テンプレート

古民家の宿のサイトでよく使われる構成（全画面のスライドショー、縦書きのコピー、客室紹介、予約への導線など）を、HTML / CSS / JavaScript で一から制作したオリジナルのテンプレートです。
トップページのほかに、**記事（地域の情報）・宿の詳細・お問い合わせ・ご予約** のページがあります。

- 文章・写真はすべてダミーです。写真は「同じファイル名で上書き」するだけで差し替えられます。
- 参考サイトの文章・写真・ソースコードは含んでいません（著作権保護のため）。レイアウトの考え方だけを参考に、独自に制作しています。
- ライブラリは不要です（jQuery やスライダーのプラグインも使っていません）。

## A. 静的サイトで確認する

1. `static` フォルダの中身をサーバーにアップロードし、`index.html` の URL を開きます。
2. お問い合わせページのフォームは見た目の確認用で、送信はされません（WordPress では Contact Form 7 のフォームになります）。
3. ご予約ページの予約画面は、`reserve.html` の `propid=00000`（2か所）を Beds24 の物件IDに書き換えると表示されます。
4. 公開する場合は、各ページの `og:url` / `og:image` を本番の URL に書き換えてください。

## B. WordPress で使う

WordPress 版は、プラグイン **「SOGETSURO Portal」** にまとめています。プラグインが行うことは次のとおりです。

- 全ページ共通のヘッダー・メニュー・フッター（電話番号・住所などは設定画面で変更）
- 記事ページ・記事一覧のテンプレート（レイアウト固定。投稿画面で書いた内容が入ります）
- 固定ページ用のテンプレート「SOGETSURO 共通レイアウト」
- CSS・JS の読み込み（SOGETSURO のページではテーマの CSS・JS を読み込まないので、テーマのデザインとぶつかりません）
- ショートコード（お知らせ一覧・記事カード・Beds24 の予約画面）と、設定画面（設定 → SOGETSURO）

> 前回お渡しした版（`01-html-block.html` などを貼り付ける方法）から変わっています。すでに貼り付けている場合は、先に「[以前の版からの移行](#以前の版からの移行)」を行ってください。

### 1. 画像をアップロードする
`static/assets/img/` の画像を、FTP やサーバーのファイルマネージャーで次の場所にアップロードします。

```
/wp-content/uploads/sogetsuro/
```

- WordPress をサブディレクトリ（例：`https://example.com/wp/`）に置いている場合は、貼り付ける HTML の `/wp-content/` と、`/reserve/` などのリンクの先頭にディレクトリ名を付けてください（エディターの一括置換が便利です）。
- `journal-*.jpg`・`article-*.jpg` は静的サイトの見本用です。WordPress の記事では、投稿画面でアップロードした写真が使われます。

### 2. プラグインを入れる
1. 「プラグイン → 新規追加 → プラグインのアップロード」で `wordpress/sogetsuro-portal.zip` を選び、インストールして有効化します。
2. 同じ画面で「Contact Form 7」を検索し、インストールして有効化します。

### 3. パーマリンクを設定する
「設定 → パーマリンク」で「投稿名」を選んで保存します（`/reserve/` のような URL になります）。

### 4. カテゴリーを作る
「投稿 → カテゴリー」で、記事の分類を作ります。

| 名前 | スラッグ | 使いみち |
| --- | --- | --- |
| お知らせ | `news` | 営業案内・メディア掲載など。**トップページの「お知らせ」欄には、このカテゴリーの記事だけが並びます**（子カテゴリーも含みます） |
| 町歩き・食と酒・手仕事・季節のこと など | 半角英数字で自由に | 地域の記事。トップページの「町のよみもの」欄と記事一覧に並びます |

- 「未分類」は削除できないため、名前とスラッグを書き換えて使ってください（例：町歩き ／ `machi`）。
- 「お知らせ」のスラッグを `news` 以外にする場合は、`pages/top.html` の `category="news"`・`exclude="news"` と、リンク `/category/news/` も書き換えてください。

### 5. 固定ページを作る
「固定ページ → 新規追加」で、次のページを作ります。本文には **「カスタムHTML」ブロック** を1つ追加し、`wordpress/pages/` のファイルの中身をすべて貼り付けます。

| タイトル | スラッグ | テンプレート | 本文 |
| --- | --- | --- | --- |
| トップ | `top`（自由） | SOGETSURO 共通レイアウト | `pages/top.html` |
| 町のよみもの | `journal` | 指定なし | 空のまま（記事の一覧が自動で表示されます） |
| 母屋 | `stay-omoya` | SOGETSURO 共通レイアウト | `pages/stay-omoya.html` |
| 離れ | `stay-hanare` | SOGETSURO 共通レイアウト | `pages/stay-hanare.html` |
| 蔵 | `stay-kura` | SOGETSURO 共通レイアウト | `pages/stay-kura.html` |
| お問い合わせ | `contact` | SOGETSURO 共通レイアウト | `pages/contact.html`（手順8でフォームを入れます） |
| ご予約 | `reserve` | SOGETSURO 共通レイアウト | `pages/reserve.html` |
| プライバシーポリシー | `privacy-policy` | SOGETSURO 共通レイアウト | ふつうのブロックで文章を書く |

- **管理者アカウント** で貼り付けてください。管理者以外の権限では、空室検索フォームの部品（`<input>` `<select>`）などが自動で削除されることがあります（マルチサイトではネットワーク管理者のみ貼り付けられます）。
- テンプレートは、編集画面の右側「テンプレート」で選びます。
- **ブロックテーマ（Twenty Twenty-Five など）の場合**、編集画面のテンプレート欄には「SOGETSURO 共通レイアウト」が表示されません。固定ページの一覧でページ名にマウスを乗せて「クイック編集」を開き、「テンプレート」で選んで「更新」してください。編集画面のテンプレート欄は「ページ」などのままですが、公開ページは SOGETSURO のデザインで表示されます。
- 「SOGETSURO 共通レイアウト」は、`pages/` の HTML を貼ったページはそのまま表示し、ふつうのブロックで書いたページ（プライバシーポリシーなど）は記事と同じ読みやすいレイアウトで表示します。
- 「町のよみもの」ページの「抜粋」は記事一覧の見出しの説明文に、「アイキャッチ画像」は見出しの写真になります。

### 6. 表示設定
「設定 → 表示設定」で次のようにします。

- ホームページの表示：「固定ページ」
- ホームページ：「トップ」／投稿ページ：「町のよみもの」
- 1ページに表示する最大投稿数：初期値の **10** がおすすめです（1ページ目は、大きく表示する最新の1件と、カード9件になります）。

### 7. SOGETSURO の設定
「設定 → SOGETSURO」で、次の項目を入力します。

| 項目 | 内容 |
| --- | --- |
| 基本情報 | 施設名・サブタイトル・電話番号・受付時間・住所・Instagram / Facebook の URL（ヘッダー・メニュー・フッターに表示されます） |
| ページの URL | ご予約・お問い合わせ・プライバシーポリシー（スラッグを変えたとき） |
| 予約システム（Beds24） | 物件ID（propid）・予約画面の言語 |
| 画像 | 記事一覧の見出し画像・記事ページ下の予約案内の画像・メニューを開いたときの画像 |
| 配色 | 背景・背景（サブ）・文字・アクセント・暗い背景 |
| 表示の設定 | 記事をこのデザインで表示する／テーマの CSS・JS を読み込まない／トップページのローディング画面 |

### 8. お問い合わせフォーム（Contact Form 7）
`wordpress/contact-form-7.txt` の手順どおりにフォームを作り、表示されたショートコードで、お問い合わせページの `[contact-form-7 id="ここにフォームID" title="お問い合わせ"]` を置き換えます。

- フォームの見た目は CSS で整えてあります。SOGETSURO のページでは、Contact Form 7 の自動整形（`<p>`・`<br>` の自動挿入）はオフになります。
- メールが届かない場合は、SMTP 送信用のプラグイン（WP Mail SMTP など）の導入を検討してください。

### 9. 公開して確認
- キャッシュ系のプラグインを使っている場合は、キャッシュを削除してから確認してください。
- 画像の遅延読み込みや、CSS・JS の結合を行うプラグインで表示がおかしくなる場合は、SOGETSURO のページを対象外にしてください。

## 記事の投稿（レイアウト固定）

記事は **タイトル・大見出し（H2）・小見出し（H3）・本文・写真** を入れるだけで、記事ページのデザインに自動で整います。

- 「投稿 → 新規投稿を追加」を開くと、リード文・大見出し・本文・写真・小見出しの枠が最初から入っています。灰色の案内文をクリックして文章を入れていくだけです。
- 投稿画面の右側に「記事の書き方」の案内が表示されます。
- 日付・カテゴリー・パンくず・**目次（大見出し・小見出しから自動作成）**・シェアボタン・前後の記事・あわせて読みたい・予約案内は、自動で表示されます。
- 書き方の詳しい説明は **[docs/article-manual.md](docs/article-manual.md)**（スタッフの方にそのままお渡しできます）。

## Beds24（予約システム）

- 「設定 → SOGETSURO」に Beds24 の **物件ID（propid）** を入れると、ご予約ページ（ショートコード `[sogetsuro_beds24]`）に予約画面が表示されます。未入力のあいだは「オンライン予約は準備中です」と表示されます。
- トップページ・ご予約ページの **空室検索フォーム** で選んだ「チェックイン日・泊数・大人・子ども」は、URL（`checkin` `numnight` `numadult` `numchild`）で予約画面に引き継がれます。
- **棟（部屋）ごとの予約画面**：宿の詳細ページの「この棟の空室を見る」ボタンのリンクを `/reserve/?roomid=部屋ID#sg-booking` にすると、その棟だけの予約画面になります（HTML の中にコメントで書いてあります）。ショートコードで `[sogetsuro_beds24 roomid="部屋ID"]` と書くこともできます。
- 予約画面の中身（色・文言・料金・お支払い）は、Beds24 の管理画面で設定します。
- 予約画面の高さは固定です。途中で切れる、または下の余白が大きすぎる場合は、`style.css` の `.sg-booking__frame` の `height` を調整してください。
- 参考：[Embedded Iframe（Beds24 Wiki）](https://wiki.beds24.com/index.php/Embedded_Iframe)、[Make Your Own Booking Widget（Beds24 Wiki）](https://wiki.beds24.com/index.php/Make_Your_Own_Booking_Widget)

## ショートコード
固定ページの「カスタムHTML」ブロックの中でも使えます。

| ショートコード | 内容 |
| --- | --- |
| `[sogetsuro_news count="3" category="news"]` | お知らせの一覧（日付・カテゴリー・タイトル）。`category` のカテゴリー（スラッグ）の記事だけを表示します |
| `[sogetsuro_journal count="3" exclude="news"]` | 記事のカード（写真つき）。`exclude` のカテゴリーは表示しません。`category` も指定できます |
| `[sogetsuro_beds24]` | Beds24 の予約画面。`roomid="部屋ID"` で部屋を指定できます |

## 以前の版からの移行
前回お渡しした版（HTML・CSS・JS をそれぞれ貼り付ける方法）を使っている場合は、次のものを削除してから、上の手順で設定してください。古い CSS が残っていると、新しいデザインの上に古い指定がかかって表示が崩れます。

1. 「追加CSS」に貼った `02-custom.css`（外観 → カスタマイズ → 追加CSS。ブロックテーマは 外観 → エディター → スタイル → 追加CSS）
2. カスタムJS の機能や、カスタムHTMLブロックの最後に貼った `03-custom.js`
3. テーマのフォルダに入れた `template-sogetsuro.php`
4. トップページ：テンプレートを「SOGETSURO 共通レイアウト」に変更し、本文を `pages/top.html` に貼り替え

古い CSS や古いテンプレートが残っていると、管理画面（ダッシュボード・固定ページ一覧・設定画面）にお知らせが表示されます。

## テーマについて
- クラシックテーマ（Twenty Twenty-One）とブロックテーマ（Twenty Twenty-Five）で、同じ表示になることを確認しています。
- SOGETSURO のページでは、テーマの CSS・JS を読み込みません（設定画面でオフにできます）。
- テーマによっては、記事の本文に目次・広告・関連記事などを自動で入れる機能があります（Cocoon の目次など）。SOGETSURO の記事では二重に表示されるため、テーマ側の機能をオフにしてください。

## 編集ガイド

### 色・フォント・余白を変える
- **WordPress**：「設定 → SOGETSURO」の「配色」で変更できます。
- **静的サイト**：`assets/css/settings.css` の値を書き換えます（WordPress のプラグインにも同じファイルが入っています）。

| 変数 | 用途 | 初期値 |
| --- | --- | --- |
| `--sg-c-bg` | 背景 | `#f4f1ea`（生成り） |
| `--sg-c-bg-sub` | 背景・サブ（お知らせ・目次・フォームなど） | `#ebe5da` |
| `--sg-c-text` | 文字 | `#2b2724`（墨） |
| `--sg-c-text-sub` | 補足の文字 | `#6f675d` |
| `--sg-c-accent` | アクセント（番号・予約ボタン・見出しの線） | `#8b3d2c`（弁柄） |
| `--sg-c-dark` | 暗い背景（食べる・メニュー・フッター） | `#211e1b` |
| `--sg-c-dark-text` | 暗い背景の上の文字 | `#ece6da` |
| `--sg-c-dark-accent` | 暗い背景の上のアクセント | `#c49a6c`（金茶） |
| `--sg-f-ja` / `--sg-f-en` | 和文 / 欧文フォント | Shippori Mincho / Cormorant Garamond |
| `--sg-w-inner` | コンテンツの最大幅 | `1200px` |

`settings.css` のコメントに、配色サンプル（藍・松葉・墨）も入れてあります。
※ `settings.css` は「追加CSS」には貼らないでください（ファイルとして読み込む前提で書いています）。

### 文章・リンクを差し替える
| 内容 | 探すキーワード |
| --- | --- |
| 住所・電話番号（ヘッダー・メニュー・フッター） | WordPress は設定画面。静的サイトは `〇〇` と `0000-00-0000` / `tel:0000000000` |
| 住所・電話番号（ページの本文） | `top.html`（アクセス）、`contact.html`、`reserve.html` の `〇〇`・`0000-00-0000` |
| リンク先が未設定のボタン（SNS など） | `href="#"` |
| Googleマップ | `sg-access__map-dummy` の `<div>` を、Googleマップの「共有 → 地図を埋め込む」でコピーした `<iframe>` に置き換え |

### 宿の詳細ページ

- **写真**：`<li class="sg-gallery__item">` を増減します。`href` が拡大表示する写真、`data-caption` が拡大時の説明文です。
- **建物情報**：`<div><dt>項目</dt><dd>内容</dd></div>` を1行ずつ増減します。
- **設備・アメニティ**：`<ul class="sg-amenities">` の `<li>` を増減します。
- **料金の目安**：`<table class="sg-table">` の行を増減します。
- **棟を増やす**：いずれかのページを複製して中身を書き換え、トップページの「泊まる」と、各ページの「ほかの客室」にリンクを追加します。

## 制作者向け：tools/build.py

静的サイト（`static/`）を元にして、WordPress 用のファイルを作ります。Python 3 だけで動きます。

```
python3 tools/build.py
```

1. `index.html` の共通ヘッダー・フッターを、ほかの静的ページにコピーします。
2. `wordpress/pages/*.html` を作ります（画像のパスを `/wp-content/uploads/sogetsuro/` に、ページのリンクを `/reserve/` などに変換）。
   `<!-- sg:wp ○○ -->` 〜 `<!-- /sg:wp -->` で囲んだ部分は、○○（ショートコードなど）に置き換わります。
3. `static/assets` の CSS・JS をプラグインにコピーし、`wordpress/sogetsuro-portal.zip` を作り直します。

CSS・JS・ページの HTML は `static/` 側を編集し、このツールで WordPress 用に反映してください（`wordpress/pages/` と、プラグインの `assets/` を直接編集すると、次に実行したときに上書きされます）。

## 動作環境・確認済みのこと
- 最新の Chrome / Edge / Safari / Firefox、iOS Safari、Android Chrome を対象としています。
