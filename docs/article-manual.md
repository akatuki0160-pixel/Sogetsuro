# 記事の書き方マニュアル

「町のよみもの」（地域の記事）や「お知らせ」を投稿するスタッフの方向けの説明です。

このサイトの記事ページは、**デザインが決まっています**。
入力するのは **タイトル・大見出し・小見出し・本文・写真** だけで、公開すると記事ページのデザインに自動で整います。文字の色や大きさ、フォントを変える必要はありません。

---

## 記事ページの形

記事ページには、上から次の順に表示されます。

| 表示される内容 | どこで入力するか |
| --- | --- |
| カテゴリー・日付 | 自動（右側で選んだカテゴリーと公開日） |
| タイトル | 投稿画面のいちばん上 |
| アイキャッチ画像（記事の顔になる写真） | 右側の「アイキャッチ画像」 |
| 目次 | **自動**（大見出し・小見出しから作られます） |
| リード文 | 本文の最初の段落 |
| 大見出し・小見出し・本文・写真 | 本文 |
| シェアボタン・前後の記事・あわせて読みたい・ご予約の案内 | **自動** |

新しい記事は、トップページの「町のよみもの」や記事一覧にも、新しい順に自動で並びます。

---

## 1. 新しい記事を開く

管理画面の左のメニューで **「投稿」→「新規投稿を追加」**（WordPress のバージョンによっては「新規追加」）を押します。

本文には、最初から次の枠が入っています。灰色の案内文をクリックして、文章を入れていくだけです。

1. リード文
2. 大見出し
3. 本文
4. 写真
5. 小見出し
6. 本文
7. 大見出し
8. 本文

使わない枠は、そのまま空にしておけば表示されません（気になる場合は、ブロックを選んでツールバーの「︙」→「削除」で消せます）。

## 2. タイトルを入れる

いちばん上の「タイトルを追加」に、記事の題名を入れます。

- 目安は **20〜35文字** です。
- 例：「朝七時の路地で出会った、町のいつもの風景」

## 3. 本文を書く

### リード文（最初の段落）
記事の書き出しです。何についての記事かを **2〜3行** で書きます。
この文章は、記事一覧やトップページのカードにも紹介文として表示されます（先頭の90文字ほど）。

### 大見出し（H2）
話の区切りごとに入れる見出しです。**「見出し」ブロックの H2** を使います。
目次に番号付きで載り、上に線が入ったデザインで表示されます。

### 小見出し（H3）
大見出しの中を、さらに分けたいときに使います。**「見出し」ブロックの H3** です。
目次では、大見出しの下に少し下げて表示されます。

- H2 と H3 は、見出しブロックを選んだときに上に出るツールバーの「H2」を押すと切り替えられます。
- 大見出しの下に小見出し、の順番で使ってください（小見出しだけを続けて使わない）。

### 本文（段落）
ふつうの文章です。**Enter** で次の段落になります。段落の途中で改行だけしたいときは **Shift + Enter** です。

- 1つの段落は、長くても4〜5行を目安に区切ると読みやすくなります。
- 大事な言葉は **太字**（Ctrl + B、Mac は ⌘ + B）にできます。太字は控えめに使ってください。
- リンクは、文字を選んでツールバーの「リンク」ボタンで付けられます。

### 写真
**「画像」ブロック** を使います。「アップロード」でパソコン・スマホの写真を、「メディアライブラリ」で前にアップロードした写真を選びます。

- 写真の下の **「キャプションを追加」** に書いた文章は、写真の下に小さく表示されます（なくても大丈夫です）。
- 右側の設定の **「代替テキスト」** に、写真の内容を短く書いてください（例：「朝の光がさしこむ石畳の路地」）。目の不自由な方の読み上げや、検索に使われます。
- スマホで撮った写真は、そのままアップロードして大丈夫です（大きすぎる写真は WordPress が自動で縮小します）。
- **横長の写真** がおすすめです。縦長の写真は、画面いっぱいの高さで大きく表示されます。

### ブロックの増やし方
- 空の段落で **「/」（半角スラッシュ）** を入力すると、ブロックの種類を選べます（例：「/見出し」「/画像」「/リスト」）。
- 画面左上の **「＋」** ボタンからも追加できます。

## 4. 右側の設定をする

画面右側の「投稿」タブで、次の項目を設定します（右側が表示されていないときは、右上の四角いアイコン「設定」を押します）。

| 項目 | 内容 |
| --- | --- |
| **カテゴリー** | 記事の分類を **1つだけ** 選びます（町歩き・食と酒・手仕事・季節のこと・お知らせ など）。 |
| **アイキャッチ画像** | 記事のいちばん上と、一覧のカードに表示される写真です。**横長の写真**（1600 × 1067px 程度）を選んでください。記事ページでは、上下が少し切れて横長に表示されます。 |
| 抜粋（任意） | 一覧のカードに表示される紹介文を、自分で書きたいときだけ入れます。空欄なら、リード文が使われます。 |
| URL（任意） | 記事のアドレスの最後の部分です。半角英数字の短い言葉にすると、SNS で共有したときにすっきりします（例：`morning-walk`）。日本語のままでも表示はできます。 |

※ アイキャッチ画像がない記事は、一覧ではロゴマークの入った枠が表示されます。

## 5. 確認して公開する

1. 右上の **「プレビュー」** で、実際の見え方を確認します（「モバイル」を選ぶとスマホでの見え方も確認できます）。
2. 問題がなければ **「公開」** を押し、もう一度出てくる「公開」を押すと完了です。
3. 途中でやめるときは **「下書き保存」** を押しておくと、あとで続きから書けます。

**日時を決めて公開したいとき（予約投稿）**：右側の「公開」の日時を押して未来の日時にすると、ボタンが「予約投稿」に変わります。

**公開したあとで直したいとき**：「投稿 → 投稿一覧」で記事のタイトルを押し、直してから「更新」を押します。

## 使えるブロック

| やりたいこと | ブロック | 表示のされ方 |
| --- | --- | --- |
| 大見出し | 見出し（H2） | 上に線が入り、目次に番号付きで載ります |
| 小見出し | 見出し（H3） | 左に線が入り、目次に載ります |
| 文章 | 段落 | ― |
| 写真 | 画像 | キャプションは写真の下に小さく表示されます |
| 箇条書き・手順 | リスト | 箇条書きと、番号付き（1. 2. 3.）が使えます |
| 人の言葉・お店の方のひとこと | 引用 | 背景色つきの枠で表示されます |
| 営業時間・料金・距離など | テーブル | 表の形で表示されます |
| 話の区切り | 区切り | 細い線が入ります |
| 動画 | YouTube（埋め込み） | 横幅いっぱいに表示されます |
| ほかのページへの案内 | ボタン | 墨色の四角いボタンで表示されます |

これ以外のブロック（カラム・カバーなど）も使えますが、デザインは調整されていません。

---

## しないでほしいこと

- **文字の色・大きさ・フォントの変更**（デザインが揃わなくなります）
- **見出し「H1」を使うこと**（記事のタイトルが H1 です）
- **段落を太字にして見出しの代わりにすること**（目次に載らず、見出しのデザインにもなりません）
- **本文に目次を自分で作ること**（目次は自動で作られます）
- 写真を文章の代わりに使うこと（文字の入った画像は、スマホでは小さくて読めません）

---

## お知らせを書くとき

カテゴリーで **「お知らせ」** を選ぶと、トップページの **「お知らせ」欄**（日付とタイトルの一覧）に表示されます。「町のよみもの」の欄には表示されません。
営業日のご案内などの短いお知らせは、アイキャッチ画像がなくても大丈夫です。

## 公開前のチェックリスト

- [ ] タイトルは入っていますか（20〜35文字が目安）
- [ ] 最初の段落に、記事の紹介（リード文）を書きましたか
- [ ] 大見出しは「見出し」ブロックの **H2**、小見出しは **H3** になっていますか
- [ ] 写真に「代替テキスト」を入れましたか
- [ ] カテゴリーを **1つ** 選びましたか
- [ ] アイキャッチ画像（横長）を設定しましたか
- [ ] プレビューで、パソコンとスマホの見え方を確認しましたか

## 困ったときは

**目次が表示されない**
大見出し・小見出しが、合わせて2つ以上あるときに目次が表示されます。見出しが「段落」を太字にしたものになっていないかも確認してください。

**見出しのデザインにならない**
「見出し」ブロックになっているか確認してください。段落を見出しに変えるには、ブロックを選んでツールバーのいちばん左のアイコンを押し、「見出し」を選びます。

**一覧のカードの紹介文を変えたい**
右側の「抜粋」に紹介文を入れてください。

**トップページに記事が出てこない**
「公開」になっているか（下書き・予約投稿のままになっていないか）を確認してください。トップページの「町のよみもの」には新しい3件、「お知らせ」にはお知らせの新しい3件が表示されます。

**記事を消したい**
「投稿 → 投稿一覧」で、記事のタイトルにマウスを乗せて「ゴミ箱へ移動」を押します（30日間はゴミ箱から元に戻せます）。
